# Story 2.4：俏皮动作编排与讲话结束反馈

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a 评审者,
I want 小狗在准备、讲话和结束时有俏皮但克制的动作,
so that 它像有生命的小宠物，而不是静态开合嘴。

## Acceptance Criteria

1. Given 用户通过文本或示例触发讲话流程, When App 进入准备/思考阶段, Then 小狗嘴巴保持 `closed`, And 舞台动作表现为耳朵竖起、看向用户或轻微歪头之一。
2. Given 小狗处于 `speaking`, When 讲话动画运行, Then 嘴巴保持可观察的 `open/talking`, And 至少有一种低幅度俏皮动作, 如轻微点头、耳朵轻弹、身体律动或尾巴小摆。
3. Given 讲话中存在装饰动作, When 用户观察嘴巴区域, Then 头部、耳朵、身体和尾巴不得遮挡嘴巴, And 舞台、输入区、状态摘要尺寸不得因动作发生布局跳动。
4. Given 讲话结束, When 完成反馈开始, Then 小狗进入 `done`, 嘴巴为 `closed`, And 出现一次短反馈, 如眨眼、轻摆尾或开心表情。
5. Given 完成反馈结束, When 系统返回待机, Then 小狗回到 `idle`, 嘴巴为 `closed`, 主 CTA 和示例入口恢复可用。
6. Given 用户开启减少动态或测试注入 `ReduceMotionPolicy.Reduced/Static`, When 准备、讲话或完成状态渲染, Then 耳朵、头部、身体和尾巴等装饰动作降低或冻结, And `speaking` 嘴巴状态仍可观察。
7. Scope boundary: 本 Story 不新增真实 Android `TextToSpeech` 发声、音频播放、播放时钟、`LipSyncTimeline`、文本高亮、波形、时间轴 UI、延迟校准、上传音频、麦克风、权限、网络、数据库、真实 AI 或新三方依赖。
8. Validation: `:app:testDebugUnitTest`, `:app:assembleDebug`, `:app:compileDebugAndroidTestKotlin`, `:app:lintDebug` 必须通过；如 `adb devices` 有可用设备, 运行并记录 `:app:connectedDebugAndroidTest`。

## Dev Notes

### 当前 Story 目标

Story 2.3 已完成最小开闭口规则: `speaking` 张口, 非 `speaking` 闭口。Story 2.4 不应重新设计嘴型或同步系统, 只把已有 `DogActionCue` / `DogMotionProfile` 转化为可见、可测、克制的宠物动作, 并补齐讲话结束后的 `done` 短反馈和回待机流程。

关键验收不是“动作多”, 而是:

- 准备阶段有回应感, 但嘴巴闭合。
- 讲话中嘴巴仍是最高视觉优先级。
- 完成反馈短、清楚、闭口。
- 减少动态时不丢失讲话嘴和状态语义。

### Architecture Compliance

- 状态改变必须在 reducer/store 层表达; Composable 不得根据文本内容、按钮文案或私有 `remember` 状态自行推断业务状态。
- `PetStagePlaceholder` 和 `DogMouthRenderer` 只消费统一 `SpeechDemoState` 派生的 mouth/action state。
- 文本和示例入口共享同一状态流、busy guard、嘴巴规则和完成反馈。
- 默认 UI 仍只包含顶部状态栏、宠物舞台、文本输入、示例入口和轻量状态摘要。
- 不恢复上传、麦克风、波形、时间轴、文本高亮、延迟校准或完整调试台。

### Library / Framework Notes

- 使用项目已有 Compose 动画 API 即可: `animateFloatAsState`, `animateDpAsState`, `rememberInfiniteTransition`, `infiniteRepeatable`, `keyframes`, `tween`, `snap`。
- Android 官方 Compose 动画 quick guide 说明 `rememberInfiniteTransition` + `infiniteRepeatable` 适合连续重复动画, `snap` 可瞬时跳到目标值; 当前 `ReduceMotionPolicy` 已用这个思路冻结装饰动作。
- Android 官方 Compose semantics 文档说明 semantics 同时服务 TalkBack 和测试框架; 2.4 的动作反馈必须体现在 `contentDescription` 或等价 semantics 中, 不能只做不可测视觉动画。
- `ValueAnimator.getDurationScale()` 返回系统动画缩放因子, scale 为 `0` 会让 Animator 动画立即结束; 当前 `AndroidAnimatorScaleProvider` 已用它映射减少动态策略, 不需要新增系统设置读取方式。

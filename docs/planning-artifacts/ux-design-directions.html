数字狗语音口型 Demo - iPad UX 设计方向

这些方向用于比较第一版 iPadOS 展示 MVP 的信息架构、视觉重心和调试强度。推荐方向不是选最丰富的界面，而是选最能证明“可爱好看 + 口型同步可信”的界面。当前平台决策已调整为 iPad 展示端，不再以网页为目标。

A 宠物舞台优先 B 精准调试双栏 C 剧场聚焦 D 工程控制台 E iPad 竖屏 F AI 状态预览

宠物舞台优先
